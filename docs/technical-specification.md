## 1. Назначение и область применения

1.1. Модуль позволяет запускать команды AutoCAD, AutoLISP-функции и .NET-команды **одиночными клавишами**
(например `1`, `2`, `3`) и сочетаниями клавиш **без нажатия Enter**. Сейчас такие клавиши печатаются в
командную строку.

1.2. Клавиши перехватываются **только когда фокус клавиатуры находится в области рисования** активного чертежа.
В командной строке, палитрах, ленте, диалогах, встроенных текстовых редакторах и других программах клавиши
работают как обычно.

1.3. Если во время нажатия горячей клавиши **выполняется команда**, модуль по умолчанию **прерывает её** и
запускает команду, назначенную клавише.

1.4. Поддерживаемые продукты: AutoCAD 2020, 2021, 2022, 2023, 2024 (64-bit, полные версии) и вертикальные
продукты на их основе (Civil 3D, Architecture, MEP, Mechanical, Map 3D). AutoCAD LT **не поддерживается**: он не
загружает внешние модули. AutoCAD 2025+ (.NET 8) — этап 4 (раздел 10).

## 2. Термины

| Термин | Значение |
|---|---|
| Горячая клавиша (hotkey) | Клавиша с модификаторами (Ctrl, Shift, Alt), которой в конфигурации назначен макрос. |
| Макрос | Строка, которая отправляется в AutoCAD: `_LINE`, `_ZOOM _E`, `(c:MyFunc)`, имя .NET-команды. Синтаксис как в макросах CUI: `^C` — отмена, `^[` — Esc, `\n` — Enter, пробел — Enter. |
| Область рисования | Окно активного документа (`Document.Window`) и его дочерние окна, кроме окон текстового ввода. |
| Активная команда | `CMDNAMES` не пуст или `CMDACTIVE` ≠ 0. |
| Запрос (prompt) | Ожидание ввода внутри команды: точка, расстояние, число, строка, ключевое слово, выбор объектов. |
| Прерывание | Отправка последовательности отмены (по умолчанию `^C^C`, как Esc Esc) перед макросом. |

## 3. Функциональные требования

| № | Требование |
|---|---|
| F1 | Модуль перехватывает `WM_KEYDOWN`/`WM_SYSKEYDOWN` через `Application.PreTranslateMessage` до их обработки AutoCAD. |
| F2 | Перехват выполняется только если сообщение адресовано области рисования (п. 4.5). |
| F3 | Для перехваченной горячей клавиши сообщение «съедается» (`Handled = true`): символ не попадает в командную строку и в динамический ввод. Соответствующий `WM_KEYUP` тоже «съедается». |
| F4 | Модуль определяет, выполняется ли команда, по `CMDNAMES` и `CMDACTIVE`. |
| F5 | Если команда не выполняется, запускается макрос клавиши (`Document.SendStringToExecute`). |
| F6 | Если команда выполняется, действует политика клавиши (п. 4.13): `Interrupt` (по умолчанию) прерывает команду и запускает макрос; `PassThrough` передаёт клавишу как обычный ввод; `Transparent` запускает макрос прозрачно (`'ZOOM`), не прерывая команду. |
| F7 | Набор чисел остаётся возможным (п. 4.10, 4.12): цифровой блок клавиатуры — отдельные клавиши; уже начатый ввод не прерывается; для клавиши можно указать типы запросов, в которых она остаётся вводом. |
| F8 | Пока выполняются команды редактирования текста (`MTEXT`, `TEXT`, `DDEDIT`, …; список настраивается), горячие клавиши не действуют. |
| F9 | Пока выполняется сценарий (`.scr`, бит 4 `CMDACTIVE`), горячие клавиши не действуют (настраивается). |
| F10 | Удержание горячей клавиши (автоповтор) не запускает команду повторно и не печатает символы. |
| F11 | Назначения хранятся в XML-файле (раздел 5). Файл перечитывается командой без перезапуска AutoCAD. Если в файле ошибка, выводится понятное сообщение (какой элемент и что не так), и остаётся прежняя конфигурация. |
| F12 | Служебные команды (раздел 6): включить, выключить, переключить, перечитать конфигурацию, вывести список назначений, включить или выключить диагностический журнал. |
| F13 | Клавиши задаются кодами виртуальных клавиш и не зависят от раскладки: `Q` и `Й` — одна клавиша. |

## 4. Правила обработки нажатия

Правила проверяются **по порядку** для каждого сообщения клавиатуры. Срабатывает первое подходящее.
Реализация: `HotKeyEngine.Process` в [`HotKeyEngine.cs`](../src/ACadHotKey.Core/HotKeyEngine.cs).

| № | Условие | Действие |
|---|---|---|
| 4.1 | Значение `CMDNAMES` изменилось с прошлого нажатия | Сбросить признак «пользователь печатает» (п. 4.10) и продолжить проверку. |
| 4.2 | `WM_KEYUP`/`WM_SYSKEYUP` | «Съесть», если нажатие этой клавиши было «съедено», иначе пропустить. |
| 4.3 | Другое сообщение, не нажатие (`WM_CHAR` и т. п.) | Пропустить. |
| 4.4 | Модуль выключен (`ACHK_OFF` или `enabled="false"`) | Пропустить. |
| 4.5 | Фокус не в области рисования: `MSG.hwnd` не равен `Document.Window.Handle` и не является его потомком (`IsChild`), **или** класс окна содержит строку из `DeniedWindowClasses` (по умолчанию `Edit`, `RichEdit`, `ComboBox`) | Пропустить. |
| 4.6 | Клавиша (с модификаторами) не назначена | Учесть ввод (п. 4.10), пропустить. |
| 4.7 | Автоповтор (бит 30 `lParam`) | «Съесть», если первое нажатие было обработано, иначе пропустить. |
| 4.8 | Выполняется команда из `ExcludedCommands` (с учётом прозрачных, например `LINE'DDEDIT`, и префиксов `_ . - +`) | Пропустить. |
| 4.9 | `CMDACTIVE` содержит бит 4 (сценарий) и включён `ignoreDuringScript` | Пропустить. |
| 4.10 | Включён `passThroughWhileTyping`, в текущем запросе уже введён символ, и клавиша печатает символ (без Ctrl и Alt) | Пропустить, то есть клавиша становится частью ввода. Признак сбрасывается после Enter, пробела, Esc, при смене команды и после срабатывания горячей клавиши. Функциональные клавиши и Ctrl-сочетания работают всегда. |
| 4.11 | Команда не выполняется | Выполнить макрос: `макрос + Enter`. |
| 4.12 | Тип текущего запроса указан в `passThroughOnPrompts` клавиши | Пропустить (ввод). |
| 4.13 | Команда выполняется. Политика клавиши (или `whenCommandActive` корневого элемента): | |
| 4.13a | — `PassThrough` | Пропустить (ввод). |
| 4.13b | — `Transparent` | Выполнить `'` + макрос + Enter. Если макрос начинается с `'` или `(`, он не меняется. |
| 4.13c | — `Interrupt` (по умолчанию) | Выполнить `cancelSequence` + макрос + Enter. По умолчанию `^C^C`. |

«Выполнить» означает: «съесть» сообщение (`Handled = true`) и вызвать
`doc.SendStringToExecute(текст, activate: true, wrapUpInactiveDoc: false, echoCommand: echoMacro)`.
Если макрос уже заканчивается на Enter или пробел, Enter не добавляется.

Ошибки внутри обработчика перехватываются и записываются в журнал. Сообщение при этом передаётся AutoCAD
без изменений. Исключение не должно выйти из обработчика цикла сообщений.

## 5. Формат конфигурации

5.1. Файл `ACadHotKey.config.xml` ищется по порядку:

1. `%APPDATA%\ACadHotKey\ACadHotKey.config.xml` — пользовательский;
2. рядом с `ACadHotKey.dll` — поставляемый пример [`config/ACadHotKey.config.xml`](../config/ACadHotKey.config.xml).

5.2. Пример:

```xml
<ACadHotKey enabled="true"
            whenCommandActive="Interrupt"
            cancelSequence="^C^C"
            passThroughWhileTyping="true"
            ignoreDuringScript="true"
            echoMacro="true">
  <!-- Дополнительно к встроенному списку (MTEXT, TEXT, DTEXT, DDEDIT, ...); keepDefaults="false" — заменить список -->
  <ExcludedCommands keepDefaults="true">MYTEXTCMD</ExcludedCommands>
  <DeniedWindowClasses keepDefaults="true"></DeniedWindowClasses>

  <HotKey key="1" macro="_LINE"   description="Отрезок" />
  <HotKey key="2" macro="_PLINE"  description="Полилиния" />
  <HotKey key="3" macro="_CIRCLE" description="Круг" />
  <HotKey key="6" macro="_OFFSET" passThroughOnPrompts="Distance Double Integer" description="Подобие" />
  <HotKey key="Q" macro="_ZOOM _E" whenCommandActive="Transparent" description="Показать всё" />
  <HotKey key="Ctrl+Shift+D" macro="(c:MyLispFunc)" />
  <HotKey key="Num0" macro="ACHK_TOGGLE" whenCommandActive="Transparent" />
</ACadHotKey>
```

5.3. Атрибуты корневого элемента `ACadHotKey`:

| Атрибут | Значения | По умолчанию | Назначение |
|---|---|---|---|
| `enabled` | `true`/`false`/`1`/`0` | `true` | Включение модуля. |
| `whenCommandActive` | `Interrupt`, `PassThrough`, `Transparent` | `Interrupt` | Политика по умолчанию (п. 4.13). |
| `cancelSequence` | строка макроса | `^C^C` | Префикс прерывания. Например `^[^[` (Esc). Вариант «как правая кнопка мыши» — открытый вопрос Q2. |
| `passThroughWhileTyping` | bool | `true` | Правило 4.10. |
| `ignoreDuringScript` | bool | `true` | Правило 4.9. |
| `echoMacro` | bool | `true` | Показывать отправленный макрос в командной строке. |

5.4. Элементы `ExcludedCommands` и `DeniedWindowClasses` содержат список через запятую, точку с запятой или
пробел. При `keepDefaults="false"` встроенный список заменяется.

5.5. Элемент `HotKey`:

| Атрибут | Обязателен | Значения |
|---|---|---|
| `key` | да | Модификаторы `Ctrl`, `Shift`, `Alt` и клавиша через `+`. Клавиши: `0`–`9`, `A`–`Z`, `F1`–`F24`, `Num0`–`Num9`, `NumAdd`, `NumSubtract`, `NumMultiply`, `NumDivide`, `NumDecimal`, `Space`, `Tab`, `Enter`, `Esc`, `Backspace`, `Insert`, `Delete`, `Home`, `End`, `PageUp`, `PageDown`, стрелки, знаки `` ` - = [ ] \ ; ' , . / `` (или `Plus`, `Minus`, …), а также код `0x..`. |
| `macro` | да | Макрос (раздел 2). |
| `whenCommandActive` | нет | Политика клавиши; по умолчанию берётся из корневого элемента. |
| `passThroughOnPrompts` | нет | Типы запросов, где клавиша остаётся вводом: `Point`, `Corner`, `Distance`, `Angle`, `Double`, `Integer`, `String`, `Keyword`, `Selection`, `Entity`, `NestedEntity`. |
| `description` | нет | Текст для `ACHK_LIST`. |

5.6. Одна и та же клавиша не может быть назначена дважды. Неизвестные клавиши, политики и типы запросов,
а также пустой макрос считаются ошибкой загрузки (F11).

## 6. Служебные команды

| Команда | Прозрачная | Действие |
|---|---|---|
| `ACHK_ON` / `ACHK_OFF` | да | Включить или выключить перехват (до перезапуска AutoCAD). |
| `ACHK_TOGGLE` | да | Переключить. Удобно назначить на сочетание с Ctrl в CUI или на клавишу модуля. |
| `ACHK_RELOAD` | нет | Перечитать конфигурацию (п. 5.1). |
| `ACHK_LIST` | нет | Вывести состояние, путь к конфигурации и список назначений. |
| `ACHK_DIAG` | да | Включить или выключить диагностический журнал `%TEMP%\ACadHotKey.log`: каждое сообщение клавиатуры, `hwnd`, класс окна, цепочка родительских окон, `CMDNAMES`, `CMDACTIVE`, тип запроса, решение и причина. Журнал также включается переменной окружения `ACADHOTKEY_TRACE=1`. |

## 7. Нефункциональные требования

| № | Требование |
|---|---|
| N1 | **Производительность.** Обработчик вызывается для каждого оконного сообщения. Для сообщений не от клавиатуры он сразу возвращает управление. Для нажатий выполняется чтение двух системных переменных, несколько вызовов Win32 (`IsChild`, `GetClassName`, `GetKeyState`) и один поиск в словаре. При выключенном журнале нет ввода-вывода. Задержка нажатия не должна быть заметна пользователю. |
| N2 | **Надёжность.** Исключение не выходит из обработчика (п. 4). Ошибка конфигурации не выгружает модуль. |
| N3 | **Совместимость.** Одна сборка `ACadHotKey.dll` (`net47`, x64), собранная против API AutoCAD 2020 (`AutoCAD.NET` 23.1.0), работает в 2020–2024. Сборка против API каждой версии 2020–2024 проверяется скриптом [`experiments/build-against-all-autocad-versions.sh`](../experiments/build-against-all-autocad-versions.sh). |
| N4 | **Тестируемость.** Логика решений (раздел 4) и разбор конфигурации не зависят от AutoCAD (`ACadHotKey.Core`, `netstandard2.0`/`net47`) и покрыты модульными тестами. |
| N5 | **Журналирование** выключено по умолчанию. |
| N6 | **Сборка** — `dotnet build` или Visual Studio 2019/2022. AutoCAD на машине сборки не нужен: ссылки берутся из NuGet. |

### 8.B. Ручные (в каждой версии AutoCAD 2020–2024)

Подготовка: `NETLOAD` → `ACadHotKey.dll`, затем `ACHK_DIAG` (журнал `%TEMP%\ACadHotKey.log`), пример конфигурации.

| № | Действие | Ожидаемый результат |
|---|---|---|
| M1 | Курсор над чертежом, команд нет, нажать `1` | Запускается `LINE`. Символа `1` в командной строке нет. |
| M2 | Во время `CIRCLE` (запрос центра) нажать `1` | `CIRCLE` прерывается, запускается `LINE`. |
| M3 | Во время `LINE` (запрос второй точки) нажать `3` | `LINE` завершается, запускается `CIRCLE`. Уже построенные отрезки остаются. |
| M4 | Во время `MOVE` с перетаскиванием (jig) нажать `1` | Перемещение отменяется, запускается `LINE`. |
| M5 | Щёлкнуть в командной строке, нажать `1` | `1` печатается в командной строке. |
| M6 | Фокус в палитре «Свойства» (поле ввода), нажать `1` | `1` вводится в поле. |
| M7 | `MTEXT`, в редакторе нажать `1` | `1` вводится в текст. |
| M8 | Во время `LINE` набрать `@100<45` с основной клавиатуры | Вводится полностью, потому что после `@` действует правило 4.10. |
| M9 | `OFFSET`, на запросе расстояния набрать `100` | Вводится, если запрос распознан как `Distance` (зависит от Q3). Иначе ввести с цифрового блока. |
| M10 | Во время `LINE` нажать `Q` | Выполняется прозрачный `'ZOOM _E`, `LINE` продолжается. |
| M11 | Удерживать `1` 2 секунды | Одна команда `LINE`, без повторных запусков. |
| M12 | `ACHK_OFF`, нажать `1`; `ACHK_ON`, нажать `1` | Сначала печатается `1`, потом запускается `LINE`. |
| M13 | Испортить XML, `ACHK_RELOAD` | Понятное сообщение об ошибке. Старые назначения работают. |
| M14 | Переключиться на другой чертёж, нажать `1` | Команда запускается в активном чертеже. |
| M15 | Русская раскладка, нажать `Q` (`Й`) | Срабатывает так же, как в английской. |
| M16 | Включить и выключить динамический ввод (`DYNMODE`), повторить M1–M3 | Результат не зависит от `DYNMODE`. |
| M17 | Открыть `%TEMP%\ACadHotKey.log` после M1–M16 | Есть строки с решением и причиной. По ним уточняются вопросы раздела 9. |

## 9. Открытые вопросы

| № | Вопрос | Предложение по умолчанию |
|---|---|---|
| Q1 | Что делать, если во время запроса числа (длина, радиус) нажата цифра-горячая клавиша **до** начала набора? | Прерывать команду (как в issue). Числа вводить с цифрового блока или после `@`/`-`/`.`. Для отдельных клавиш задать `passThroughOnPrompts`. |
| Q2 | «Эффект правой кнопки мыши» — это Enter (завершить и принять результат, как при щелчке правой кнопкой в `LINE`) или Esc (отмена)? | По умолчанию Esc (`^C^C`): он всегда прерывает команду. Enter не всегда завершает команду, иногда принимает значение по умолчанию. Если нужен Enter, задать `cancelSequence="\n"` и проверить по M2–M4. |
| Q3 | Генерирует ли AutoCAD 2020–2024 события `Editor.PromptingForXxx` для запросов **встроенных** команд, или только для запросов из .NET (`Editor.GetPoint` и т. п.)? | Проверить по журналу `ACHK_DIAG` (строки `prompt …`), M9. Если не генерирует, `passThroughOnPrompts` действует только для запросов .NET-команд, а для встроенных используются цифровой блок и правило 4.10. |
| Q4 | Приходит ли `WM_KEYDOWN` в `PreTranslateMessage` во время команд и jig в каждой версии 2020–2024? | Проверить по M2–M4. Если нет, запасной вариант — хук `WH_GETMESSAGE` для потока AutoCAD в том же модуле (research.md, раздел 2.3). |
| Q5 | Нужны ли разные наборы клавиш для разных рабочих пространств или профилей? | На первом этапе — один файл на пользователя. |
| Q6 | Нужен ли графический редактор назначений? | Нет, XML и `ACHK_RELOAD`. |

## 11. Установка

11.1. Ручная загрузка: команда `NETLOAD` → `ACadHotKey.dll`.

11.2. Автозагрузка: папка [`bundle/ACadHotKey.bundle`](../bundle/ACadHotKey.bundle) с `ACadHotKey.dll` и
`ACadHotKey.config.xml` в `Contents\` копируется в `%APPDATA%\Autodesk\ApplicationPlugins\`. `PackageContents.xml`
ограничивает версии: `SeriesMin="R23.1"`, `SeriesMax="R24.3"`. Если автозагрузка блокируется политикой
безопасности (`SECURELOAD`), папка добавляется в `TRUSTEDPATHS`.
