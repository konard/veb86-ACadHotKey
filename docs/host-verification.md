# Протокол приёмки в AutoCAD

Связанные документы: [ТЗ, 8.B](technical-specification.md), [матрица реализации](implementation-status.md).

**Статус: НЕ ВЫПОЛНЕН.** В среде разработки Linux нет Windows, AutoCAD или его лицензии.
Сборка против эталонных DLL и тесты с подменами событий не проверяют настоящий цикл сообщений,
интерфейс AutoCAD или выполнение команд. В таблице ниже нет результатов, полученных в AutoCAD.

## Подготовка воспроизводимого испытания

1. Зафиксировать commit SHA (`git rev-parse HEAD`), Windows, продукт AutoCAD, версию и обновления
   (`ABOUT`), раскладку, `DYNMODE`, `SHORTCUTMENU`, путь конфигурации из `ACHK_LIST`.
2. Выполнить `bash experiments/package.sh`; установить готовый пакет по README. Для `NETLOAD`
   выбрать сборку из `Contents/2020` или `Contents/2021-2024` соответственно. Использовать тестовый DWG.
3. Включить `ACHK_DIAG`; очистить старый журнал перед новой сессией. После проверки выключить журнал
   и сохранить `%TEMP%\ACadHotKey.log` вместе с SHA и скриншотами командной строки/состояния чертежа.
4. Выполнить **каждый** M1–M17 из раздела 8.B в **каждой** версии 2020–2024. Фокус означает щелчок
   в области рисования, а не только положение указателя мыши над ней.
5. Для M9 использовать временное назначение `1` с `passThroughOnPrompts="Distance Double Integer"`
   (пример назначает такое исключение только клавише `6`). Проверить и `OFFSET`, и свою .NET-команду
   с `Editor.GetDistance`. Не считать срабатывание правила «уже набирается текст» доказательством события.
6. Дополнительно удержать горячую клавишу, изменить Ctrl/Shift; выключить модуль прозрачной командой
   во время удержания; повторить с перезагрузкой настроек. До отпускания не должно быть повторов/символов.
7. Проверить `enabled="false"` → `ACHK_RELOAD` → `ACHK_ON`, XML с неизвестным атрибутом/политикой,
   возврат к чертежу после диалога, ввод чисел после выбора точки мышью и закрытие/создание чертежа.

## Что блокирует завершение issue

* F1/F3/F5/F6/F10: не доказана доставка и подавление сообщений в реальном AutoCAD, включая команды и jig (Q4).
  Если M2–M4 покажут отсутствие `PreTranslateMessage`, потребуется проверить и реализовать фильтр
  `WH_GETMESSAGE` потока AutoCAD. Добавлять непроверенный хук вместо протокола не означает пройти приёмку.
* F2/F8/F13: не проверены настоящие классы окон, текстовые редакторы, фокус и раскладки.
* F7: неизвестна доставка `PromptingForXxx` от встроенных команд (Q3). Если события отсутствуют,
  тип запроса нельзя объявлять распознанным; потребуется исследование источника состояния запроса.
* N3 и этапы 2–3: загрузка, автозагрузка и поведение в каждой установленной версии не проверены.

Issue и PR остаются незавершёнными до заполнения протокола реальными результатами и устранения выявленных
отклонений. Скриншоты не созданы, поскольку интерфейс AutoCAD в этой среде недоступен.
